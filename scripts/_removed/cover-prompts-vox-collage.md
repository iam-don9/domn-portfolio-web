# VOX 拼贴风格封面提示词 · 14 个技能

> 风格 = `retro-torn-collage`（复古手撕拼贴 / Vox 式照片+撕纸信息图）
> 画幅 = **16:9**（skills 页卡片封面槽）
> 主标题 = 各技能中文名（中英混排，标题印在撕纸/剪报上但仍醒目）
> 用法：复制每条 `PROMPT` 文本，直接进你的生图工具（gpt-image / nano / Seedance-图 均可）
> 通用视觉底座（每条都已融合，无需另加）：手撕纸边、旧报章杂志碎片、胶带、纸贴纸与投影、复印颗粒、半调网点、油墨错位、手写批注、剪报标题块、刻意随意但主次分明的编辑式平衡。
