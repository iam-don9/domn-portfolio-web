商业 IP 视觉创作

domn-ip-visual · IP视觉共创 v1.0.0

一个 IP 从一句模糊的想法，到能直接交付的整套视觉资产：先定方向，出主形象，锁住核心资产，然后铺三视图、表情、动作、换装、海报和周边。要的是可复用的流程，不是一次性出一张图。

  • 创意一上来就开画，风格四不像、返工不断
  • 换场景复用时一致性崩坏，每次都像换了个 IP
  • 只出单张图，攒不成可复用的视觉资产

解法

方向先定，图后生 → 造型和画风拆开 → 身份锁死、表现可变 → 识别点少而狠，缩到很小也认得出。

不接：纯商业策略、授权、生产咨询超出范围

核心结构

两个文件，跑完整个流程

domn-ip-visual/
├── meta.yaml   · 身份卡
└── SKILL.md    · 执行说明书

meta.yaml

技能的身份与元数据：中文名「IP视觉共创」、版本号、分类标签、中英文摘要与描述、作者与来源。

给技能市场 / 索引读取，不参与执行。改这里只影响「它叫什么、归哪类」。

SKILL.md

真正的执行说明书：五条核心原则、八态状态机、视觉创作十阶段、17 页提案模板、最高优先级约束。Agent 干活时读的就是它。

内部按 read_when / 原则 / 状态机 / 十阶段 / 模板 / 优先级规则 分节，越改越像一份会逐渐长大的设计文档。

没有脚本、没有额外资源逻辑全在 SKILL.md
