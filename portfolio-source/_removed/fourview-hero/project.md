# 角色四视图

## 项目故事

- 项目背景或起点：每次做多镜头短片，角色跨镜头都会漂。追到根上是缺少一个硬参照，于是先解决参照物问题。
- 项目目标：产出一套能被后续所有镜头复用的标准四视图。
- 受众或使用场景：内部资产，配套所有角色类短片。
- 最终成果：正面、侧面、背面、四分之三侧四个标准角度。
- 我的具体贡献：全部。

## 工具和方法

- 使用的模型和工具：Midjourney 出初稿，ControlNet 锁定姿态线，Photoshop 做对齐校正。
- 关键工作流程：先定比例网格，再生成四个角度，最后统一轮廓与配色。
- 技术限制：模型无法保证四视图的像素级一致，必须人工校正。

## 创作过程证据

1. 概念或草图：比例网格与姿态线。
2. 参考方向：角色设定惯例（正面/侧面/背面/四分之三）。
3. 提示词或脚本迭代：四视图共用同一段描述，只切换角度词。
4. 生成结果对比：校正前后的轮廓差异。
5. 人工修改或合成：Photoshop 对齐肩线与眼线。
6. 最终交付：四视图 PNG。

## 关键决策

- 决策 1 及原因：四视图共用一段描述、只换角度词。差异越小，一致性越好。
- 决策 2 及原因：接受人工校正这一步。指望模型一次到位会无限返工，不如把校正成本算进流程。
- 遇到的问题及解决方式：背面视图的一致性最差，最后用正面图镜像加局部重绘解决。

## 提示词、脚本或配置说明

- 提示词或脚本说明：角度词固定为 front / side / back / three-quarter，不换说法。
- 重要参数：ControlNet 权重 0.85，低于 0.8 姿态会漂。
- 可复用技巧：一致性靠参照物，不靠调参。
