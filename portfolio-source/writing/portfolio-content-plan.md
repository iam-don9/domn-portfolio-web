# 作品集内容规划

未来的作品集应当通过证据传达能力，而不是只罗列互不相关的最终成品。

## 建议的内容顺序

1. 个人定位：介绍 DOMN / Domn 是谁，以及主要从事什么类型的工作。
2. 精选作品：展示一组代表项目，之后由每个项目的 `Featured` 字段控制是否入选。
3. 创作过程：展示精选成果背后的决策、迭代和具体制作能力。
4. 能力地图：覆盖 AI 图片、角色设计、AI 视频、AI 工具、skill、TVC 和视觉设计。
5. 联系方式：提供一个清晰的对外联系入口。

## 按作品类型规划展示方式

| 类型 | 应重点收集的证据 | 适合的展示方式 |
| --- | --- | --- |
| AI 图片 | 视觉方向、提示词迭代、筛选和后期修图 | 时间线 + 画廊 |
| 角色设计 | 轮廓、表情、服装和多角度设定 | 设定表 + 局部对比 |
| AI 视频 | 脚本、分镜、关键帧、剪辑和声音 | 分镜 + 播放 |
| AI 工具 | 问题、界面、工作流程和结果 | 问题-方案-结果 |
| Skill | 触发方式、输入、处理过程、输出和可复用规则 | 工具演示 + 案例 |
| TVC | Brief、视觉方案、镜头设计和成片 | 分镜 + 成片 |
| 视觉设计 | Brief、视觉系统、迭代和应用场景 | 前后对比 + 画廊 |

## 选择项目的建议

- 资料准备完成后，先选择 3—6 个项目作为精选作品。
- 优先选择能够展示不同能力、同时整体风格不冲突的项目。
- 以过程深度决定优先级：没有可解释过程的精致成果，往往不如一个决策清晰、过程完整的成果更有说服力。
