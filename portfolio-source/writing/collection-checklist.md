# 资料收集清单

## 个人资料

- [ ] 品牌名、艺名和对外显示名
- [ ] 短简介和长简介
- [ ] 能力、工具和工作流程优势
- [ ] 对外联系方式和社交链接
- [ ] 头像和品牌素材

## 每个项目

- [ ] 中文标题，以及适合时补充英文标题
- [ ] 类型、年份、状态和 Featured 标记
- [ ] 项目背景、目标、受众、成果和个人贡献
- [ ] 使用的工具、模型和工作流程
- [ ] 按时间顺序整理精选过程证据
- [ ] 关键决策和问题解决过程
- [ ] 提示词、脚本或配置说明
- [ ] 带文件名的素材清单
- [ ] 建议的未来展示方式

## 素材筛选标准

当一份素材能够证明某个决策、迭代、技术或结果时保留它。删除重复内容和信息量很低的失败结果。
