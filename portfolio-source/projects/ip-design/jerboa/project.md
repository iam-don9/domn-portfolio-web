# 跳鼠 JERBOA

## 项目故事

- 项目背景或起点：一档自然科普短视频需要一个能反复出现的吉祥物，用来串场和收尾。真实动物里，跳鼠形态独特、动作喜感、辨识度高，是天然的 IP 坯子。
- 项目目标：设计出一只「可爱、可延展、可记忆」的原创跳鼠 IP，覆盖表情、动作、周边与实物化转译。
- 受众或使用场景：短视频出镜角色 + 社媒周边素材，也是后续角色设计方法论的范例。
- 最终成果：1 套角色设定（三视图 + 表情系统 + 动作系统）+ 1 张主视觉海报 + 周边 / 毛绒延展。
- 我的具体贡献：参考研究、形象提案、三视图与表情动作系统、周边与 3D 转译监督。

## 工具和方法

- 使用的模型和工具：Midjourney v6 出方向与关键帧，Photoshop 做统一与精修，整体走 domn-ip-visual 的「商业 IP 视觉」流程。
- 关键工作流程：先锁定参考与体态锚点，再出三视图定结构，最后才放开表情与动作。结构不稳就狂加表情只会越改越乱。
- 技术限制：大耳朵 + 大眼睛的组合极易生成「幼态过载」，每一次出图都要压住比例，避免变成通用萌物而非跳鼠。

## 创作过程证据

1. 概念或草图：从真实跳鼠照片提炼体态关键词（后腿长、耳大、眼大、尾细），作为所有提示词的锚点。
2. 参考方向：自然纪录片里的跳鼠动态，作为动作系统的姿态基准。
3. 提示词或脚本迭代：主视觉海报改了多轮，难点在「舞台感」与「可爱度」的平衡——太舞台就不可爱，太可爱就没记忆点。
4. 生成结果对比：三视图要求三张是同一只，重点校验耳朵角度与眼距是否一致。
5. 人工修改或合成：表情系统的 6 张在 Photoshop 里统一了瞳色与高光位置，确保跨表情可识别。
6. 最终交付：主视觉 + 三视图 + 表情 + 动作 + 周边 + 毛绒，共 7 张成体系物料。

## 关键决策

- 决策 1 及原因：先结构后表情。角色设计的可信度来自比例一致，表情只是比例之上的情绪，顺序反了必然返工。
- 决策 2 及原因：用「参考锚点词」约束生成，而不是每次重写整段。真实动物特征（耳大、后腿长）作为固定前缀，模型就不会漂移成别的小动物。
- 决策 3 及原因：周边与毛绒单独出一版，验证形象在脱离平面后的体积成立。IP 不能只活在海报里，要能落地。

## 提示词、脚本或配置说明

- 提示词或脚本说明：固定锚点顺序为「物种特征 → 姿态 → 情绪 → 画质」，变量只插在姿态与情绪位。
- 重要参数：Midjourney 的 `--s 250` 降低风格化，避免每轮风格漂移把跳鼠画成别的物种。
- 可复用技巧：真实动物做 IP，先用照片提炼 3 个不可替代的形态关键词，把它们焊死在提示词开头。

## 未来展示建议

- 推荐展示方式：character-sheet + gallery
- 建议展示顺序：参考锚点 → 三视图 → 表情 → 动作 → 周边 / 毛绒
- 希望观众理解的重点：IP 形象设计是系统工程，不是一张好图，而是能复用的角色规则。
