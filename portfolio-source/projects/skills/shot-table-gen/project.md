# 镜头表生成器

## 项目故事

- 项目背景或起点：每次开新片都要手写镜头表，重复劳动且格式不统一，分镜软件又太重，不值得为一个短片开。
- 项目目标：输入一段剧情大纲，输出结构化镜头表（景别、运镜、时长、功能），直接能进分镜。
- 受众或使用场景：自己的前期流程，也是可复用的内部工具。
- 最终成果：一个命令行脚本，输入 txt 大纲，输出 Markdown 镜头表。
- 我的具体贡献：需求定义、规则设计、脚本实现。

## 工具和方法

- 使用的模型和工具：纯 Python，无外部模型依赖，规则写死在模板里。
- 关键工作流程：先识别段落边界，再给每段匹配默认运镜与景别，时长按情绪权重分配。
- 技术限制：不试图理解语义，只做结构化拆分。创意判断仍由人做。

## 创作过程证据

1. 概念或草图：先手动画了镜头表的字段结构。
2. 参考方向：影视分镜表的通用字段。
3. 提示词或脚本迭代：规则从均分时长改成按情绪词加权。
4. 生成结果对比：手写镜头表与脚本输出并置，结构一致。
5. 人工修改或合成：输出后再人工微调运镜。
6. 最终交付：可用脚本。

## 关键决策

- 决策 1 及原因：不做语义理解，只做结构化。理解交给人，机器只省掉格式劳动。
- 决策 2 及原因：输出 Markdown 而不是专有格式。任何编辑器都能改，不绑定工具。
- 遇到的问题及解决方式：段落切分错误。按空行加序号双重判断，比单看标点稳。

## 提示词、脚本或配置说明

- 提示词或脚本说明：大纲约定每段一行、情绪词用方括号，脚本据此分配时长权重。
- 重要参数：基础时长 6 秒，情绪词加权正负 2 秒。
- 可复用技巧：工具只解决重复劳动，创意环节留给导演。
