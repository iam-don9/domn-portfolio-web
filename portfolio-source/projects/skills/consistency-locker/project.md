# 一致性锁

## 项目故事

- 项目背景或起点：云海旅人和肖像系列都暴露同一个问题，多镜头一致性靠人盯着，容易漏。每次生成都要手动把参照图描述写进提示词，既慢又容易不一致。
- 项目目标：把角色或场景设定图固化为一致性锁，生成时自动注入，模型不需要自己记住。
- 受众或使用场景：自己的生成流程，特别适合系列化与多镜头项目。
- 最终成果：一个注入器，读取设定图的描述文件，拼接到每条生成提示词前。
- 我的具体贡献：锁定机制设计、描述文件规范、脚本实现。

## 工具和方法

- 使用的模型和工具：Python 拼提示词，ImageMagick 做设定图与生成图的比对缩略图。
- 关键工作流程：设定图 → 提取结构化描述 → 注入每条提示词头部 → 生成 → 缩略图比对。
- 技术限制：只解决描述一致，不解决模型自身的形变。

## 创作过程证据

1. 概念或草图：先定义设定图必须包含的字段。
2. 参考方向：四视图、色板、材质卡。
3. 提示词或脚本迭代：从整段粘贴改成按字段选择性注入。
4. 生成结果对比：有无一致性锁的两组生成并置。
5. 人工修改或合成：比对缩略图人工挑废片。
6. 最终交付：注入器脚本。

## 关键决策

- 决策 1 及原因：用描述文件而非图片直传。模型读文字比读图稳定，且可版本管理。
- 决策 2 及原因：选择性注入而不是全量。某些镜头不需要全部字段，全量反而干扰。
- 遇到的问题及解决方式：长提示词被模型截断。按镜头类型裁剪字段，控制总长度。

## 提示词、脚本或配置说明

- 提示词或脚本说明：设定描述按脸型、发色、服装、光线锚点四字段组织，注入时按镜头需要取用。
- 重要参数：注入位置固定在提示词头部，权重最高。
- 可复用技巧：一致性是前期工程，不是生成时运气。
