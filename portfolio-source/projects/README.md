# 作品项目

在对应的作品类型目录下创建一个项目文件夹。项目文件夹内保持平铺。

| 目录 | 用途 |
| --- | --- |
| `ai-images` | AI 图片系列、视觉实验、图片宣传项目 |
| `character-design` | 角色概念、角色设定表、表情、服装和世界观 |
| `ai-video` | AI 视频、动态测试、短片和作品集视频 |
| `ai-tools` | AI 工具、实用程序、工作流、原型和生产系统 |
| `skills` | 可复用的 AI skill、提示词系统和智能体工作流 |
| `tvc` | TVC、产品片和商业宣传片 |
| `visual-design` | 品牌视觉、海报、编辑设计、界面或宣传设计 |

每个项目都使用 `project-template.md` 作为 `project.md` 的起始模板。
