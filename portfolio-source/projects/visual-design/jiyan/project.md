# 霁颜 JIYAN

## 项目故事

- 项目背景或起点：新锐东方植萃护肤品牌需要一个「既东方又不老气」的视觉系统——多数国货护肤要么过度国风（烫金祥云），要么完全西式（冷白极简），中间的「东方呼吸感」是空白位。
- 项目目标：建立一套可落地的品牌 VI：主视觉、包装系统、品牌规范与空间应用四层。
- 受众或使用场景：品牌提案与电商/线下渠道物料，作品集商业全案案例。
- 最终成果：1 张主视觉 KV + 包装系统 + 品牌规范板 + 空间应用示意，共 4 张成体系物料。
- 我的具体贡献：视觉策略、风格锚定、全部视觉生成与规范整理。

## 工具和方法

- 使用的模型和工具：GPT-image 2.5 主生成，Photoshop 微调统一色温。
- 关键工作流程：先定「东方留白」的精神锚点（原研哉式的克制与留白），再以 Aesop 式材质语言约束包装，最后才生成空间应用。风格锚点先行，物料逐层推导。
- 技术限制：中文品牌字在生成里偶有形变，「霁颜 东方植萃」经多轮校验确保笔画准确。

## 设计系统资产清单

- 色彩：米白 `#F5F1EB`（底）/ 雾绿 `#A8B5A0`（辅助）/ 青瓷绿 `#5E8B7E`（品牌主色）/ 琥珀 `#8C6A4A`（材质点缀）。
- 字族：中文细宋（品牌标题）、极细无衬线拉丁（JIYAN / 辅助信息），字重不超过 400。
- 图形：细线圆形 logo（叶形负形），只用单色描边，不做渐变。
- 网格：规范板采用大留白 + 单侧内容区的非对称秩序，留白占比不低于 55%。
- 材质：磨砂玻璃、哑光卡纸、原木、真实植物——禁止高反光与金属质感。

## 创作过程证据

1. 概念或草图：先列「东方感」的三条路径（国风纹样 / 山水意境 / 留白材质），选定留白材质路线。
2. 参考方向：原研哉（Kenya Hara）的留白哲学 + Aesop 的包装材质克制。
3. 提示词或脚本迭代：主视觉改多轮，重点压住「绿」的饱和度——青瓷绿偏灰才高级，翠绿立刻俗气。
4. 生成结果对比：包装三瓶的色温统一是难点，琥珀与雾绿的搭配比全绿更耐看。
5. 人工修改或合成：规范板的色带与中文字在后期校准对齐。
6. 最终交付：4 张成体系物料，构成完整 VI 提案叙事。

## 关键决策

- 决策 1 及原因：不用任何国风纹样。东方感来自材质与留白，不来自符号堆砌——这是与大多数国货护肤拉开差距的关键。
- 决策 2 及原因：规范板单独出一张。品牌全案的可信度来自「可复用」，规范板证明这套视觉能被执行，而不只是一张好看的图。
- 决策 3 及原因：空间应用收尾。全案的最后一层是「走进空间还成立」，这是提案打动甲方的临门一脚。

## 提示词、脚本或配置说明

- 提示词或脚本说明：所有生成图使用「真实参考名锚定 + 强制降噪后缀」的中文短 prompt 结构，风格槽位锚定原研哉与 Aesop，避免形容词堆砌。
- 重要参数：1K 画质档，high 质量；主视觉 3:4 竖幅，规范板 4:3。
- 可复用技巧：品牌全案类生图先写「设计系统资产清单」再生成，色彩与材质约束写进每条 prompt，四张图才能像一个系统。

## 未来展示建议

- 推荐展示顺序：主视觉 → 包装 → 规范板 → 空间
- 希望观众理解的重点：我能交付的不是四张图，而是一套可执行的品牌视觉规则。
