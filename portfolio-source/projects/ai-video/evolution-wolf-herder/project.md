    血统决定了你的猎物本能，但炼金术与重铁决定了你能活到哪一天。

    将你的视线投向大陆的最北端——【霜绝谷】。
    这是一片连呼吸都会冻结肺腑的极寒禁地。传闻中，这片风雪深渊被一支不可一世的“狼王铁骑”绝对统治。数以万计的重铠巨狼踏碎冰原，它们身披重甲、手执巨斧与重弩，以最冷酷的军纪绞杀着一切擅闯者。

    但如果你真的有命走进霜绝谷，你会发现一些令人毛骨悚然的“违和感”：

    为什么那支战无不胜的巨狼铁军，在被利刃拦腰斩断时，不仅不会发出半声哀鸣，断口处甚至没有一滴滚烫的鲜血，只有流淌着黑气的冰渣？
    为什么它们冰冷的胸腔里，根本听不到心跳的声音？

    在这片永远下着暴雪的深渊谷底，埋藏着古老地脉的炼金熔核。而在这座冰封王座的最深处，那个能让万千死尸如臂使指、将恐怖狼群像牲口一样驱赶的“牧狼人”，究竟是怎样的怪物？

    如果在这个“狼吃羊”的天经地义的世界里，那个在幕后掌控着几万头不死恶狼的魔王，其实是一只最温顺、最弱小、连草都快嚼不动的食草老羊呢？

    嘘。
    风雪声变大了，狼王的进军骨号已经吹响。

# 进化论：牧狼人

## 项目故事

- **项目背景或起点**：想做一个「反派不可怕，温柔才可怕」的预告。常规暗黑奇幻靠狼群和血浆吓人，这次反过来——把最温柔的语气放在最残忍的画面上。
- **项目目标**：用 60 秒建立四个空间、九个角色、一条完整的反转逻辑，并且让每一秒都能被单独抽出来当海报。
- **受众或使用场景**：个人作品集的旗舰案例，同时也是这套世界观长片的融资/招商预告。
- **最终成果**：60 秒预告的完整生产包（规格规范 / 双轨时间线剧本 / 世界观与解剖学约束表 / 九角色资产总表 / 四场景资产 / 分镜执行总览表 12 卡 / 关键帧提示词 KF001–KF011 / 生成单元 GU001–GU005 / 声音与混音时序表）。其中《猫鹰对决》与《雪兔》两段已成片。
- **我的具体贡献**：世界观设定、解剖学约束表、全部角色与场景资产、分镜执行总览、生成提示词工程、生成与迭代、剪辑与声音设计。

## 工具和方法

- **使用的模型和工具**：Seedance 2.5 生成，Midjourney 出角色与场景概念，Photoshop 做角色设定总表与海报版式，DaVinci Resolve 剪辑与混音。
- **关键工作流程**：先写死**解剖学约束表**——每个角色的兽化率、躯干特征、足部特化结构、战斗力学，全部量化（如「C07 狼卫处刑官 80% 异化重兽 / 双足立柱增生狼爪 / 落地如山崩」）。资产先锁解剖，生成才不会漂。
- **技术限制**：环摇长镜头与多人同框是 AI 生成的死穴。解法是把 360 度环绕拆成四个明确的「掠过点」，每个点只负责一个角色的标志性动作，再要求「镜头内部禁止跳切」。

## 创作过程证据

1. **世界观与解剖学约束**：九个角色逐条写兽化率与足部结构。足部是最容易被模型忽略的部位，所以单独列一栏——「趾行猫足 / 反屈兔掌 / 双瓣裂蹄 / 立柱增生狼爪」这些词一写进去，角色的站姿和运动力学就跟着变了。
2. **资产总表**：角色 + 场景 + 道具 + LOGO 与海报，逐项配概念图提示词。三视图用于锁体型与装配位置，确保任何机位下不出现肢体畸变。
3. **分镜执行总览表**：12 张分镜卡，逐卡写清时序区间、景别与运镜、动作表现与台词对位、对应资产、关键帧编号。表里有四列是交叉引用的，任何一卡改动都能查到牵连范围。
4. **生成与迭代**：《猫鹰对决》与《雪兔》各跑了初版与迭代版。初版暴露两个问题——近身兵刃容易粘连穿模、巨斧横扫后的倒飞轨迹不符合人体力学。迭代版逐条修掉。
5. **声音设计**：四条轨（对白 / 音乐 / 音效 / 环境）按 60 秒逐段对齐。空间三结尾做了「画面闪白 ＋ 全频段抽空 1 秒」的静音处理，用听觉的真空给第四空间的反转让位。

## 关键决策

- **决策 1：反派用画外音，而且全程只有笑**。羊尊的四段台词全部是哄孩子的语气，画面上却是一场处刑。明确写死「严禁羊尊出现狰狞咆哮表情」——一旦他变脸，恐怖感就降级成普通的威胁。
- **决策 2：小羊羔是全片的情绪锚点**。观众通过一个问出「爷爷，那我们会被吃掉吗」的孩子，理解这套秩序的残酷。没有它，万狼叩首只是一张壮观的图。
- **决策 3：把最强的段落放在最后，而且不给结局**。360 度环摇集结之后，撞击前 2 帧硬切黑场。预告的任务是让人想看正片，不是讲完故事。
- **遇到的问题及解决方式**：狼潮在远景里容易糊成一团黑。解决办法是先把狼卫做成四型可辨识的编制（弩箭 / 电锯 / 重甲 / 重锤），再进远景——有编制，才读得出「万狼」。

## 提示词、脚本或配置说明
